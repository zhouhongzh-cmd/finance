补充说明：

- 期指模块现已包含保证金快照、现货指数备源和 `16` 合约覆盖
- 当前集成测试结果为 `36` 通过、`0` 失败、`0` 跳过
- 已接入 `A50 + Top10 合约加密资产池` 期现溢价模块，支持独立调度、SQLite 快照、参数页和看板
- 当前看板已切换为“分页查看 + 当前页手动刷新”的老 GUI 风格
- `alert_history.notified` 已接入“至少一个通知渠道发送成功”的本地状态回写
- 调度层已按策略拆分出独立 job，并为舆情增加独立低频扫描
- 调度层现已升级为“模块独立时钟 + GUI 可调”，并增加金属巡航/盯盘任务
- 共享运行参数已迁移到仓库内的 `config/runtime_settings.json`
- 金属阈值已支持在 GUI 中按品种编辑，并单独写入 `config/metals_thresholds.json`
- 已增加日度数据保留清理任务，默认保留最近 `14` 天报警历史、保证金快照、期指快照与金属快照
- 期指主表与金属主表已调整为固定业务顺序，前置字段按监控决策优先展示，其余字段保留在后
- 期指策略现已要求“贴水率阈值 + 年化贴水率阈值”同时满足才报警
- 已增加数据源健康度、配置变更审计和任务运行状态三类运维视图
- 高频快照已切到“分钟级去重 + 值变化才写 + 保底定时写入”，数据库增长速度已明显收敛
- `alert_history` 已改为同一标的全系统只保留最新一条报警
- 可转债链路已增加上市/退市状态过滤，未上市和已退市转债不会进入策略
- 舆情链路已补股票名称映射，报警与看板默认显示 `名称(代码)`
- 期指阈值已拆成 `IH / IF / IC / IM` 分品种配置，并支持共享基线与本机 local 覆盖
- 参数设置页已改成按模块折叠分组，模块开关、时钟和阈值现已集中到各自模块面板，并支持模块级单独保存
- 期现溢价阈值已支持按 `A50` 与 `加密资产 × 合约桶` 配置，并单独写入 `config/premium_thresholds.json`

### 当前仍未闭环

- `alert_history.notified` 已完成本地回写，但仍未细分多渠道送达状态与崩溃后补发语义
- 期指现货与保证金链路仍依赖外部站点可用性，当前通过备源保证运行连续性
- SQLite 当前已加显式写锁，但长期高压写入下仍建议升级为单写队列
- 金属 live 取数仍依赖外盘商品和汇率接口可用性，当前通过 fallback 与跳过单品种保证连续运行
- 加密资产 live 取数当前优先依赖 `Gate API`，A50 仍依赖 `yfinance` 与 `akshare`；当前通过按资产 / 桶位跳过保证连续运行
