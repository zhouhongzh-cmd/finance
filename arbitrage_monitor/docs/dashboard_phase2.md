# Phase 2 看板设计

> 关联基线: `docs/requirements_codex_v1.md`
> 说明: 本文档承接 Phase 2 看板的专题设计细节，不替代主需求书。

---

## 1. 目标

Phase 2 看板优化的目标固定为：

- 优先服务盘中决策效率
- 采用“轻量扩展数据层 + 多视图工作台”
- 继续使用 Streamlit
- 不做完整前端重构
- 不把研究型指标直接写成当前已实现能力

---

## 2. 默认形态

Phase 2 默认采用 3 个固定视图：

- `机会台`
- `复盘台`
- `系统台`

### 2.1 机会台

- 当前有效机会
- 期指期限结构板
- 转债候选池
- 快速筛选

**快速筛选定义**：
- 筛选项：策略类型、资产类别、报警级别
- 交互方式：多选下拉框
- 筛选项支持即时过滤，无需提交按钮

**异常态/空态处理**：
- 快照为空：显示"暂无数据"占位提示
- 数据过期（>5分钟）：显示黄色警告标签"数据可能过期"
- 接口失败：显示红色错误状态及错误信息

### 2.2 复盘台

- 历史报警表
- 各策略报警统计
- 重复触发标的
- 近 7 日分布

**异常态/空态处理**：
- 无历史数据：显示"暂无报警记录"
- 数据加载中：显示加载动画

### 2.3 系统台

- 数据源状态灯
- 降级状态
- 数据新鲜度
- 数据库与通知状态

**颜色语义使用场景**：
| 级别 | 颜色 | 使用场景 |
|------|------|----------|
| CRITICAL | 红色 (#FF4B4B) | 严重告警、接口完全失败 |
| WARNING | 黄色 (#FFA500) | 数据过期、部分降级 |
| INFO | 蓝色 (#4A90D9) | 正常信息 |
| OK | 绿色 (#4CAF50) | 数据源正常 |
| FALLBACK | 黄色 | 降级运行中 |
| FAILED | 红色 | 数据源失败 |

**期指价差率颜色梯度**：
| 条件 | 显示语义 | 颜色 |
|------|----------|------|
| `价差率 >= 0` | 升水或无贴水 | 绿色 |
| `-1% < 价差率 < 0` | 轻微贴水 | 蓝色 |
| `-2% < 价差率 <= -1%` | 中度贴水 | 黄色 |
| `价差率 <= -2%` | 深度贴水 | 红色 |

说明：

- 价差率在看板中使用 `normalized_rate = -discount_rate` 口径，正值表示升水，负值表示贴水。
- 颜色只作为扫描辅助，不替代策略阈值；是否报警仍由 `strategies/futures_strategy.py` 的普通阈值和年化阈值共同决定。

**刷新策略**：
- 机会台：手动刷新（用户点击刷新按钮）
- 复盘台：页面加载时自动刷新
- 系统台：每 30 秒自动刷新

**移动端可读定义**：
- 字号下限：14px
- 允许横向滚动：是
- 表格列数限制：移动端显示 3 列关键数据

### 2.4 布局骨架

Phase 2 的文字线框固定为：

```text
[顶部状态栏: 最新快照时间 / 数据来源 / 数据状态]
[视图切换: 机会台 | 复盘台 | 系统台]

机会台:
  [筛选栏: 策略类型 | 资产类别 | 报警级别]
  [当前有效机会矩阵]
  [期指期限结构板]
  [转债候选池]

复盘台:
  [历史报警表]
  [策略统计]
  [近 7 日分布]

系统台:
  [数据源状态灯]
  [降级状态]
  [数据库与通知状态]
```

约束：

- 不在当前阶段引入独立前端或高保真设计稿。
- 若后续进入完整 UI 重构，再补充视觉线框图和组件规格。

## 3. 数据层范围

Phase 2 看板允许新增少量结构化快照，不继续只依赖 `alert_history.message` 文本。

最低要求如下：

- `futures_snapshot`
- `cb_snapshot`
- `source_health_snapshot`

用途约束：

- `futures_snapshot` 支撑期指期限结构板、排序和保证金占用展示
- `cb_snapshot` 支撑转债候选池与来源标识
- `source_health_snapshot` 支撑系统台状态灯和降级状态
- `alert_history` 继续保留为事件流，不替代快照层

---

## 4. 交互约束

如果进入 Phase 2，看板应按以下交互约束演进：

- 继续使用 Streamlit
- 使用 `tabs` 或等价的多视图切换方式实现工作台
- 首页优先使用卡片、矩阵和短表，而不是长页堆叠
- 颜色语义固定：
  - `CRITICAL` 红
  - `WARNING` 黄
  - `INFO` 蓝
  - 数据源 `OK` / `FALLBACK` / `FAILED` 使用绿 / 黄 / 红
- 移动端本阶段只保证可读，不单独设计专用布局
